The Memory Crypt

Memory champions don't have better brains. They put each thing they want to remember in a place, and make it strange. This crypt has seven niches, and each one looks different.

  1. Write 2–7 things you need to remember, one per line.
  2. Memorize: walk the niches in order (I, II, III…) and connect each thing to the niche's decoration.
  3. Recall: the candles go out. Then name what was in each niche.
